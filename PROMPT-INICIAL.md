# Cómo arrancar

1. Descomprimí el zip. La carpeta `juego-toros` ya es el proyecto (podés renombrarla a `el-mundo-de-gliff`).
2. Si tenés dibujos o archivos de Gemini, reemplazá los de `assets/` usando el mismo nombre.
3. Abrí la terminal dentro de la carpeta y ejecutá `claude`.
4. Pegá este mensaje:

---

Hola! Vamos a hacer "El Mundo de Gliff", un juego que inventó Elías. Todo está descrito en CLAUDE.md y el orden de trabajo en PLAN.md. Las imágenes, música y sonidos ya están en assets/.

Leé esos dos archivos, mirá qué hay en assets/, inicializá git con un primer commit y hacé la etapa 1 usando las imágenes reales. Cuando termines, decime cómo abrirlo para probarlo.

---

Para seguir: "Funciona, pasemos a la etapa 2" (y así).
Para cambiar cosas, pedilas normal: "que el toro corra más lento", "que la granjera sea más grande".
